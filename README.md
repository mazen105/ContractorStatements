# مستخلصات المقاولين

تطبيق أندرويد أصلي باللغة العربية يعمل دون اتصال، بقاعدة SQLite، مع تصدير PDF متعدد الصفحات وتصدير CSV قابل للفتح في Excel.

## البناء

افتح مجلد المشروع في Android Studio (JDK 17 و Android SDK API 35) ثم نفذ:

`gradle assembleRelease`

يتطلب تنزيل Android Gradle Plugin و Kotlin Gradle Plugin أول مرة. الناتج: `app/build/outputs/apk/release/app-release-unsigned.apk`؛ وللتثبيت يلزم توقيع نسخة الإصدار بمفتاح توقيع Android، أو استخدم `gradle assembleDebug` للحصول على ملف APK موقع تلقائياً للاختبار في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات

- احفظ المستخلص قبل بدء مستخلص جديد لترحيل الكميات.
- يتم ترحيل الكمية المنفذة السابقة لكل بند وفق المشروع والمقاول ووصف البند والوحدة.
- تصدير CSV يفتح في Excel؛ لا يتضمن المشروع مكتبة XLSX خارجية.
- الأرقام المالية محسوبة باستخدام `BigDecimal` لتجنب أخطاء الفاصلة العائمة عند الجمع والضرب.
- الحفظ والتصدير يتمان محلياً، ولا يلزم أي إذن تخزين.
